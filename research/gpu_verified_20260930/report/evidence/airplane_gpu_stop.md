# Airplane：实际 GPU 第78步停止依据与隔离修复

2026-09-24。**已补齐我方实际 GPU 多项式证据，并在隔离入口中实现第78步性质停止。** 原来第79步才停止的差异来自整步hull掩盖了后半步越界；本次保持求解器和已接受前缀不变，在时间子区间上发现停止依据。

## 原配置与改动

保持19个状态/控制变量、12个物理状态，B1，h=.01、阶数6、cutoff1e-6、余项±.01、SR1000，控制周期.1、目标20周期/T2/200步。原始初值、动力学、ONNX、box/same-slope、官方输入布局和rpc-float32传输均保持。

引擎仍为 `b049d443a46e74f55e96cc50673310c6c37f51ee` 的稀疏元数据候选；没有改作者工作树。首先仅增加第77/78/79步的pre、tmv、余项与支持集保存，再在独立driver中加入时间两分检查：只对安全集合原检查尚未确定的已接受步，检查左右半步是否有某个约束下界大于0。发现越界则沿原来的Unsafe路径停止；没找到越界仍保留unknown，绝不据此宣布安全。

这是有界两分检查，不是声称对任意系统等价于原生Flow*的递归细分。本案例与原生停止步数相同；控制器浮点界/RN注入尚未资格化，仍不能据此宣称完整NNCS证明。
