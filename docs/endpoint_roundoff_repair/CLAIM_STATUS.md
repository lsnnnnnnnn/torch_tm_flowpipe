# 旧主张与修复数据的边界

旧 CPU VDP T10、Brusselator T20 是真实记录的计算完成结果，旧结构消融也是实际实验。这些数据保留原始上下界、时间、身份和摘要，标为 `OLD_UNREPAIRED_ARCHIVE`，不称为伪造或全部作废。

已确认的端点系数舍入遗漏使旧版本不能继续作为无条件正确的独立 oracle。反例证明的是局部代入操作漏包，尚未证明两条固定轨迹已经漏掉真实 ODE 解。大余项和零采样违规也不能证明两条旧轨迹仍然安全。

本轮修复后的实验必须由干净的新数值提交重新执行，标为 `FRESH_ENDPOINT_REPAIRED`。旧文件不会覆盖或重命名成新数据；未改变的 Flow* 对照标为 `REUSED_MATCHED_REFERENCE`。

修复端点操作不等于完成整个求解器的形式化证明。结论限于本轮建立的常数代入合同、实际误差传递检查及重新运行的范围。全程结果在完成之前保持未验证状态。

本轮不做性能实现、不接第三方后端、不开发 CUDA。GPU 后端选择仍未决；不能从本轮修复推导永久放弃 Huan/Xiangru，也不能以“我们的参考必然更正确”作为路线依据。
