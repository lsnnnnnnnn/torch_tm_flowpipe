# QUAD saved first batch: isolated CROWN upper-slope receipt

**Outcome: `uA=lA` on the reproduced 1,024-box first batch.** This was one new, controller-only diagnostic on the 2026 paper QUAD first-call inputs. It did not run the native plant, Flow*, a control-period loop, or the old full experiment. The original octagon production gate remains **CLOSED**.

The preflight found no QUAD/CROWN process and an unused GPU 1. [`START.json`](START.json) records the selected model path, file size and modification time, saved RPC, physical GPU 1, CPU core 12, and 120-second cap. The isolated [`probe.py`](probe.py) uses the frozen server's 12-input ONNX controller, Torch float64, disabled TF32, `BoundedModule(..., activation_bound_option='same-slope')`, the same backward `compute_bounds(..., return_A=True)` call, and exactly the 1,024 saved [RPC input boxes](../native_quad_allbox_firststep_recenter_gate_20261003_003/run/rpc.json). It records all four returned tensors before native float32 transport: `lA`, `uA`, `lbias`, `ubias`.

The single call exited 0. All arrays are finite and have the expected shapes: slopes `[1024,3,12]`, biases `[1024,3]`. The new `lA`, `lbias`, and `ubias` exactly match the old saved RPC's `T`, `u_min`, and `u_max` in **43,008/43,008 numeric positions**. The new `uA` exactly equals the new `lA` in **36,864/36,864 positions**. [`RESULT.json`](RESULT.json) records the remote comparison; an independent local [`audit_readback.py`](audit_readback.py) regenerated [`AUDIT.json`](AUDIT.json) after copying the raw files and confirmed zero mismatches. Exact equality here means equality of parsed numeric values; no digest or hash comparison was performed.

The preserved [raw arrays](RAW_COEFFICIENTS.json), [stdout](stdout.log), [stderr](stderr.log), [exit code](exit_code.txt), scripts and START/RESULT receipts permit readback. The recorded `elapsed_seconds` covers the Python `main()` body after imports and is **not** a benchmark timing. GPU 1 was idle again after the call. No second controller call was made.

Because the reproduced three old arrays match, this new `uA` supplies a same-slope **record for an identical numeric replay** of the saved first batch. It does not prove that auto_LiRPA's floating-point CROWN bounds are mathematically sound, that the server model bytes match any separate local copy, or that the native controller set encloses the actual network. In particular, the separate [exact-rational float32 transport audit](../native_quad_crown_f32_transport_gate_20261003_001/README.md) still finds that the raw ideal affine certificate does not directly certify many transported native bounds. The independent lane-0 [network residual gate](../native_quad_lane0_nn_affine_certificate_20261003_009/README.md) remains **UNDECIDED**. Later controls, remaining plant steps and the full-time reach-and-remain property remain open.
