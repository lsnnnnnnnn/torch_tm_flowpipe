# NAV robust working-P3: 25 boxes through T=6

This is one new, isolated run of the named fixed-2026-official NAV **set** ONNX with the controller author's executable state order `[x,y,speed,heading] → [speed_rate,heading_rate]`. It did not restart the historical `engine_linear_leaf_v2` robust run or the earlier one-box smoke. The physical plant is `x'=speed cos(heading), y'=speed sin(heading), speed'=u1, heading'=u2`. All 25 boxes in the original 5×5 source ledger were propagated for 30 held-control periods of 0.2 s, or 600 ODE substeps of 0.01 s. The all-time closed obstacle is `[1,2]²` in x/y; the terminal closed target at T=6 is `[-0.5,0.5]²`.

The working P3 uses order 3 with validation order 4, strict endpoint and control injection, box same-slope CROWN, and `rpc-float32` quantization mode. It ran with in-process CROWN on physical GPU1 and CPU6–9, an 11 GiB GPU allocation cap, and a 3,600 s supervisor timeout.
