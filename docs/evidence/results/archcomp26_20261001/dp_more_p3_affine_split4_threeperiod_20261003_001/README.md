# Double Pendulum more: P3 affine-split4 three-period diagnostic

This new isolated run uses the fixed 2026 continuous more-robust controller and all 225 configured initial boxes. It requests only three of the benchmark's 20 control periods: `3×0.02 s`, with four `h=0.005 s` ODE substeps per period. It is a method diagnostic, not a complete `T=0.4 s` benchmark cell or a property certificate. The earlier directed-interval first-period and full-attempt records were left untouched.

## Observed result

The [outer result](attempt/RESULT.json) is `completed/exit0`, no timeout, wall **15.463218 s**. The [inner result](attempt/data/RESULT.json) reports **12/12 numerical substeps and 2,700/2,700 accepted lane-substeps**, no broken lane, three controller evaluations, and `end_to_end_strict_certificate=false`. The author stdout prints `Step 0`, `Step 1`, `Step 2` and no final VERIFIED/UNKNOWN/Unsafe label.

The independent [saved-data scan](INDEPENDENT_SAVED_INTERVAL_SCAN.json), reproduced by `python3 scan_saved_nohash.py`, checked all 12×225 four-state tube/endpoint records: finite, ordered, accepted with solver status 0, endpoint inside the corresponding tube, and every saved tube inside `[-1.5,1.5]^4`. The smallest saved tube safety-face margin is **+0.011337384491292513**, at substep 5, lane 35, `θ̇₁` upper face. This is a complete **0.06-second numerical prefix** only; no `T=0.4 s` terminal width or full-time safety conclusion exists here.

The maximum directed controller residual widths by period are **0.1286336, 0.0613925, 0.0858196**. The earlier interval-envelope run recorded **1.8001911, 5.8371182, 22.9517874** and rejected all 225 boxes at substep 9. Only the first period has the same initial input state; later widths arise from different propagated states, so these arrays are a method diagnostic rather than same-state ratios. The new envelope intersects complete 256-subbox directed affine residual bounds with the whole-box bound; the controller-local enclosure still relies on the existing directed interval operations and does not qualify the plant/NNCS chain independently.

The scan confirms configured split counts, 225 observed lanes, and first-step pooled tube coverage of `[1,1.3]` in each physical coordinate. This run did not save a separate per-lane initial-box ledger, so those checks do not independently prove the lane-to-source-subbox mapping.
