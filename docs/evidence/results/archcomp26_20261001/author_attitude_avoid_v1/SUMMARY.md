# ARCH-COMP26 Attitude Control：Huan / Xiangru 修正 unsafe 集的新尝试

合同见[独立审计](../../../../ARCHCOMP26_ATTITUDE_CONTROL_CONTRACT_20261001.md)。这组运行使用固定官方 2026 `attitude_control_3_64_torch.onnx`、完整六维初盒、保存的作者 Taylor order 3 / `h=.05` / 控制周期 `.1`，GPU3、CPU14–17、strict plant、box/same-slope CROWN、native 输入布局和 RPC float32 系数传输。新配置把保存代码中空集错误 `-x4-0.4` 修为官方 `-x4-0.7`；不复用旧性质成绩。两方分别加载自己的 plant engine，但共享控制驱动和大部分数值路径。
