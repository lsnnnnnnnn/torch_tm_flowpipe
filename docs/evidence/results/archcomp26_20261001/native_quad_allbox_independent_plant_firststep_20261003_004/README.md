# First attempted all-box independent plant gate: method blocker at box 0

This new saved-data-only diagnostic used the prior [all-box first-step RPC and observer receipt](../native_quad_allbox_firststep_recenter_gate_20261003_003/README.md). It did not run Flow*, CROWN, a neural network, or any old experiment. No content digest or hash verification was performed.

The [first probe](probe_0_1/RESULT.json) requested only source boxes 0 and 1. The [new checker](check_saved_boxes_nohash.py) added an exact-rational guard that requires the independently constructed directed-Decimal control hull to contain the saved RPC's float32-transported affine-plus-residual hull. **Box 0 failed this method guard before any Picard substep or saved-range comparison**, so box 1 and the other 1,022 boxes were not attempted. The probe status `METHOD_UNDECIDED` is not a Flow* interval failure or an actual plant trajectory counterexample.

The [reproduction](reproduce_blocker_nohash.py) and [exact-number receipt](BLOCKER.json) isolate the defect. In the previously used `tools/check_native_quad_fullset_interval_gate_nohash.py`, `I.__neg__` applies Python Decimal's context-sensitive unary `-` to an exact binary64-derived Decimal. At the default precision 28, it rounds rather than flipping the sign exactly. For box 0's second control, the resulting Decimal lower bound is **1.25×10⁻³¹ above** the exact affine hull lower bound, so the supposed outer interval omits part of the admitted control set. The same code has `I(-r,r)` for both sine and cosine Taylor remainder radii; their unary minus is also inexact. `abs(x.lo)` and `abs(x.hi)` likewise use context-sensitive rounding before selecting the trig error magnitude; the reproduction shows `copy_abs()` is exact where `abs()` is not.

The earlier first-box [27/32 plain-box Picard comparison](../native_quad_initial_recenter_repair_gate_20261003_002/INDEPENDENT_AUDIT.json) and its resulting 20/20 composed-state total used that helper. Their saved numerical results remain historical data, but this probe means the claimed **strict outward-arithmetic qualification is not established by that helper as written**. The exact-rational x6/x10/x11 algebraic bounds are separate; the other Picard-based comparisons need a corrected rerun. No prior raw receipt was altered. The native production gate remains **CLOSED**.

The next correction is isolated in a separate diagnostic ID; this failed method probe remains preserved as the first-stop record.
