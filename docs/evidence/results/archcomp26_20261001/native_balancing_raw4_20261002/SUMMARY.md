This is the separately named `balancing-fixed-repo-raw4` profile, not the paper's unresolved five-feature controller. The isolated [native source](../../../../../tools/archcomp26_balancing_raw4_native_nohash.cpp) uses the fixed CartPole ODE, one full physical initial box `[-0.1,0.1]×[-0.05,0.05]×[-0.1,0.1]×[-0.05,0.05]`, raw `(x1,x2,x3,x4)` controller input, one force held for `0.02 s`, Flow* inner step `0.005 s`/order 6, and a planned 500 periods. The checker records every saved continuous tube after `t=8` for `x1,x3,x4∈[-0.001,0.001]`; it includes the closed boundary `t=8`, which is equivalent to the fixed specification's `(8,10]` window for a continuous trajectory and a closed target box. The C++ RPC coefficient conversion uses the author's original `asFloat()` behavior. No content digest was computed.
