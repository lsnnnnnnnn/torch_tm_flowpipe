# 两类已知问题的本地复现材料（未对外发送）

这份材料仅涉及已授权复查的历史传播、归一化两类问题。源版本与精确逐路线输出见 `SOURCE_MAP.json`、`WITNESS_CROSSCHECK.csv` 和 `raw_minimal/A.json`、`B.json`。第三方源文件不包含在我们的仓库中；重跑须具备相应源码读取权限与 CUDA 构建环境。

## 历史矩阵

三个矩阵依次为 `[[0,0],[0,0]]`、`[[1.0000000000000002,0],[-1,0]]`、`[[0,0],[0.9999999999999999,1.0000000000000002]]`。前两次传播后分别追加 J 列 `[1048576,0]`、`[0,0]`。原始 JSON 直接复用，不随机重搜。

精确最后第二分量为 `-4503599627370497/38685626227668133590597632`。当前候选 CPU/CUDA、普通/严格都返回约 `-2.328306436538697e-10` 附近的很窄区间，不包含该值。区间确切端点及每一步值全部保存在 raw JSON。对应路径为 `flowpipe.advance`、`sparse_exec.advance_sparse` → `symbolic_remainder.propagate`。当前 `propagate` 共用不分模式的点矩阵连乘。

拟议修复：旧版的 interval Phi/scalars、逐步区间矩阵更新与历史列求和可作起点；新矩阵必须包含选定尺度的倒数和线性系数乘法误差，线性多项式乘加误差须有当前 J 所有者。只在最后一次 dot 扩张不够。

## 零常数仿射归一化

两个状态独立取 `P0=float64(1.1)*u0`、`P1=float64(1.1)*u1`，各 `u∈[-1,1]`，余项 `[-2^-52,2^-52]`，常数为零。每个原像精确上界是 `4953959590107547/4503599627370496`，下界取负。

检查实际生产函数缩放并恢复后的整个像集，而非单点或系数相等。上一轮最小 sparse CPU 布局所选 s=`1.1000000000000014`、Q 系数=`0.9999999999999988`、余项半径=`2.0185873175002823e-16`，恢复上界比原像少约 `1.1102230246253265e-17`。当前回放的每个合法布局/设备也均不包含原像，布局导致的尺度差别完整保留在 raw JSON。

对应 `sparse_exec._g_precond` 及其 `advance_sparse` 调用者；dense 对应 `flowpipe.advance`。旧版裸 helper 仍与此类似，但实际严格调用者随后补记区间倒数和系数误差，故须检查完整调用链。旧版在本轮 CPU/CUDA、dense/sparse 严格局部检查中通过。

拟议修复关系为 `I_new ⊇ I/s + range(P/s-Q)`。倒数按区间求，保留点系数与精确乘法之差进入余项；新增误差以 s 恢复后还须进入未缩放当前 J，保证下步线性传播不会遗漏。真零才可压缩；极小非零与非有限值必须明确处理。以上是材料与未实施修复建议，不是已通过全时域的候选补丁。

## 重跑

用 `experiments/backend_reevaluation/crosscheck.py`，分别传 `--implementation A/B/C --source <对应目录> --witness <上一轮 known_witness_replay.json> --output <新文件>`。A/B 默认检查 CPU/CUDA；C 用 `--devices cpu`。源 SHA、实际导入路径与干净状态会在入口核对。用各自独立 extension cache；本地准确目录见 `RUN_CONTEXT.json`、`SOURCE_MAP.json`，环境命令保存在本轮执行记录。无需克隆整个历史实验或重跑两个 CPU 长时域。
