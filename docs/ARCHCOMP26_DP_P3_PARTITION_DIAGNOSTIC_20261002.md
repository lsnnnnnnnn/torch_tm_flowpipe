# ARCH-COMP 2026 DP less-robust P3 controller partition diagnostic

Date: 2026-10-02. This continues the incomplete [directed affine attempt](ARCHCOMP26_DP_P3_AFFINE_DIAGNOSTIC_20261001.md) with two **distinct** input-partition refinements. The split-4 run supplies a complete 225-box, 20-period **numerical** safety result. ## Unchanged contract and conservative refinement

Both runs retain the fixed official less-robust controller, four-state continuous DP ODE, the entire `[1,1.3]^4` initial set partitioned into 225 boxes, 20 control periods of 0.05 s, five 0.01 s plant substeps per period, and whole-time safety `[-1.7,2]^4`. Work order 3, point order 2, validation order 4, geometric reciprocal, strict injection/endpoint, and full symbolic remainder are unchanged. The only new numerical choice is the independently directed controller residual for the same global CROWN point map `T` at each period. The original `interval` and `affine` code paths and default remain unchanged when the new flag is absent.

For each physical-state input box `H = Πᵢ[lᵢ,uᵢ]`, the new routine constructs `m+1` finite, ordered binary64 boundaries on each axis, with the first and last **equal** to the stored endpoints. It evaluates all `m⁴` products of adjacent closed subintervals (`m=2` or `4`). These boxes cover `H` as real sets, with shared boundaries; the code checks boundary ordering and the recovered outer endpoints at runtime. The pre-existing directed affine evaluator computes an enclosure `Rₖ` of `NN(x)−T·x` on each subbox with the **same** `T`. The interval `[minₖ lower(Rₖ), maxₖ upper(Rₖ)]` therefore encloses the residual on `H` under that evaluator's interval-arithmetic contract. Intersecting it with the original whole-box affine enclosure remains conservative because both enclose the same exact residual. A disconnected union is **not** treated as a tighter convex set; its interval hull is used. No portion of the initial set or time horizon was discarded.

Local implementation: [partitioned affine controller](../tools/archcomp26_dp_affine_controller.py), [P3 runner](../tools/archcomp26_dp_p3_nohash.py), and [independent JSONL interval scan](../tools/audit_archcomp26_dp_p3_partition_nohash.py). Each remote attempt contains a copy of the runner, both controller modules, and the outer recorder used for that run. The split-2 source copy predates the split-4 generalization, so both are independently interpretable. No frozen engine tree was edited. Physical GPU 3 and CPU 14–17 were free before each launch; the outer time limits were 300 s and 180 s. No content digest was computed.
