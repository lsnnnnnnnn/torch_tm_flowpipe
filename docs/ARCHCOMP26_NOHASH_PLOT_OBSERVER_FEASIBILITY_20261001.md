已对保存文件作只读格式检查：P3 第一行 `x3` tube 为 `[-0.4020154393569473,0.40207317382644503]`，第 1000 行 `x3` tube 为 `[0.9583882250316996,1.0256989643985053]`，endpoint 为 `[0.9584732146312499,1.0256989643984427]`。这个 observer endpoint 与 P3 `RESULT.json` 的最终 hull `[0.9584732146312492,1.0256989633476477]` **数值不完全相同**；从 JSONL 画图时必须保留 JSONL 原值，不拿最终 hull 偷换其最后一帧。ACC 用逐项向外扩张的二进制浮点区间运算重新扫描保存 tube，最小 margin 下界为 `16.254753759211187`（第 50 步）；先前摘要用直接表达式所得 `16.25475375921129`。两者都大于零，但绘图应标明使用向外扩张的盒像，不能把新图说成独立端到端证明。

**最小实现顺序**：先为现有无哈希入口加入重复 `--overlay-geometry`，只合并严格同合同的既有 geometry 并重新校验；再为 pooled JSONL 建单独的 time–state source kind、逐行步号/有限区间/接受计数校验与 `partial` 标记；最后为 ACC 增加固定仿射投影 `(+1·x_lead)−x_ego−1.4·v_ego−10`，复用已有向外扩张区间运算。三项都应继续生成 `.geometry.json/.m/.png/.pdf/.render.json`，保存绝对来源路径、大小、配置与相邻未绑定运行证据，并用 SHA 构造器抛错的守卫烟测。现阶段不要把 P3 pooled 行伪装成 native per-lane range，也不要调用旧摘要导出路径。

**已实现的固定视图**：独立的[`archcomp26_plot_saved_nohash.py`](../tools/archcomp26_plot_saved_nohash.py) 现读取**四方** ACC 保存 tube 与 P3 QUAD pooled JSONL，生成两张图、MATLAB 脚本、逐步区间 JSON 和无内容摘要收据；见[出图包](evidence/results/archcomp26_20261001/plots/nohash_saved_20261001/SUMMARY.md)。它没有扩展通用 `flowpipe_plot_nohash.py` 的 source kind 或多方法通用合并接口。ACC 新图用保存 binary64 端点的精确有理数像和向外最终取整，最小下界为 native `16.254753759211283`、Huan/Xiangru 各 `16.165034707564207`、ours/P3 `16.434858569716976`；上述 `16.254753759211187` 是另一种逐运算向外取整的更宽扫描值，来源于不同但同样保守的派生舍入规则。
